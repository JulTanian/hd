# 1.75 更新

配置版本 `1.75.0`，Mac Apple Silicon、Mac Intel 与 Windows x64 使用同一份发行源码。

- 搜索加载和页面读取共用 15 秒期限；超时后重建隐藏窗口，后续搜索可以继续。慢加载页面仍会先读取已有结果。
- 主窗口启用沙盒；生产脚本策略收紧，限制页面跳转和弹窗。应用接口验证请求窗口、主页面和页面地址，外部链接仅允许 HTTP/HTTPS。
- 页面渲染异常时显示中文恢复提示，可重新加载。
- 本地数据写入临时文件后先同步落盘，再替换正式文件；保留保存失败回退和损坏文件保护。
- 播放页减少无下载变化时的重复目录扫描；下载任务变化后刷新分集状态。
- 整集缓冲读取设置 300 MiB 限额，避免单个异常大文件无限读取；正常流式播放、HLS 磁盘处理及下载后播放继续使用原流程。此限额不是整个进程的内存上限。
- 任务标识统一使用 UUID。版本按整数段比较，`1.74 < 1.75 < 1.76 < 1.100 < 2.0`；相同版本、较旧版本和预发行不会被提示为正式更新。

## 验证边界

定向回归覆盖安全来源、搜索超时及队列恢复、保存失败与文件同步、页面异常恢复、资源限制与版本顺序。成品构建、签名、公证、各平台检查和公开状态以本轮发行记录及 GitHub Release 为准。

Windows EXE 未签名。模拟网络与云端检查不代表真实上游长期可用，也不替代实体 Windows、Intel Mac 或启用 Gatekeeper 的干净 Mac 实测。文件同步加原子替换仍不构成所有硬件断电场景下的数据持久性保证。
