# 红果短剧 1.73

## 下载自动重试

- 临时网络故障、超时、传输不完整：即时恢复仍失败后，最多追加三轮，依次等待 10、30、60 秒。
- 取源暂不可用时保留 3、8、15 分钟等待，两种策略共享三轮重试预算。
- 下载管理显示“等待重试”、轮次和预计排队时间；可立即重试或停止。
- 批量重试失败任务不打断已有自动重试计划。暂停、取消、重启恢复与已完成文件保护继续保留。
- 不自动降低指定画质。权限、磁盘或安全拦截等问题需要处理原因后重试；不能保证所有上游下载均成功。

见 [自动重试行为与回归验证](download-auto-retry.md)。
